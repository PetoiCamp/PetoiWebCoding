Welcome to Petoi Web Coding Blocks

Program your robot by dragging and dropping blocks

This tool allows you to program Petoi robots by dragging and dropping blocks. It is compatible not only with Bittle and Nybble equipped with NyBoard, but also with Bittle X, Bittle X V2, Nybble Q, and any robot equipped with BiBoard. It supports multiple connection methods: USB, Bluetooth, and WiFi.

Mainboard Configuration

  • For products using BiBoard:
    Since Bluetooth and WiFi are already integrated into the ESP32 module on the mainboard, you only need to upload the latest firmware to it (the easiest way is to use the desktop app).
  • For products using NyBoard:
    Please refer to Setup on NyBoard.

*Chromebook Bluetooth: Connect in Chrome with Quick Connect → Bluetooth. The browser shows the device list. Do not pair the robot in the system Bluetooth settings.

*WiFi 2.4 GHz note: Many modern routers broadcast 2.4 GHz and 5 GHz at the same time. They may share one network name (SSID) and let each device connect on the appropriate band automatically. Petoi robots use 2.4 GHz WiFi. You can also connect both your computer and the robot to your phone's mobile hotspot.

1. USB Cable Connection (Most Stable)

Connect your robot to the computer using a USB cable. Click the "Connect Serial Port" button and select a port with "wchusbserial" or "usbserial" in its name.

2. Bluetooth Connection

On Windows, Mac, and Chromebook, connect Bluetooth in Chrome. Click Quick Connect and choose Bluetooth. Chrome shows the device list in the browser. Names usually start with Bittle, Nybble, Quaddle, Petoi, or Mini. Do not pair the robot in the system Bluetooth settings. After it connects, the serial monitor opens, and the Quick Connect button shows the Bluetooth name. While that link is connected, Run sends commands over Bluetooth and does not connect to the IP in the Connect Device block.

Windows Quick Connect → Bluetooth in Chrome. The browser shows the device list. Do not use the system Bluetooth settings.
Mac/Linux Quick Connect → Bluetooth in Chrome. The browser shows the device list. Do not use the system Bluetooth settings.
Chromebook Quick Connect → Bluetooth in Chrome. The browser shows the device list. Do not use the system Bluetooth settings.
Connection priority: While Quick Connect Bluetooth is connected, programs use Bluetooth and do not open Wi-Fi. Otherwise the order is USB, then Bluetooth, then Wi-Fi.

3. WiFi / Local Website Connection

Important: WiFi connection requires running the website locally due to browser security restrictions.

  1. Online mode (code.petoi.com): WiFi is NOT available. Please use USB or Bluetooth.
  2. Download local version: Click the link to download from GitHub
  3. Open index.html in your browser
  4. Now WiFi and all connection methods work!
For NyBoard, you will need an extra step to configure its WiFi module.

Quick Connect Button

Click to choose USB / Wi-Fi or Bluetooth. Bluetooth opens Chrome's device list and does not need pairing in the system settings. When Bluetooth is connected, the button shows the device name. USB / Wi-Fi uses the serial port or Wi-Fi, and the button shows the IP address.

Interface Guide

  • Block Workspace: Drag blocks from the left panel here to build your program
  • Console Log: Displays program status and debug information
  • Serial Monitor: Send commands and view replies. A Chrome Bluetooth connection uses this same monitor.

Common Blocks

  • Connect Device: The first block of every program. While Bluetooth is connected, the field shows the Bluetooth name and returns to the previous address after disconnect. Otherwise it shows the device IP, which you can also type in.
  • Motion Blocks: Control robot walking, turning, and actions (stand, sit, backflip)
  • Joint Blocks: Precisely control each joint's angle
  • Pin Blocks: Control digital/analog input and output pins
  • Sensor Blocks: Read ultrasonic, camera, gesture and other sensor data
  • Music Blocks: Play notes and melodies

Important Notes

  • Every program must start with the "Connect Device" block
  • Before running code, connect with USB, Bluetooth, or Wi-Fi
  • Acrobatic moves (front/back flips) put high stress on robot joints - use with caution
  • When using USB, if no port is found, try unplugging and reconnecting the cable
  • On Windows, Mac, and Chromebook, connect Bluetooth in Chrome with Quick Connect. Do not pair the robot in the system Bluetooth settings.

More Details

For more detailed interface introduction and advanced usage, please refer to the Documentation Center.

For products using NyBoard (Bittle / Nybble):

  1. Please refer to NyBoard Preparation and upload the Mind+ mode firmware to the NyBoard first.
  2. Compatible sensors include:
    • Analog sensor modules: light sensor, infrared distance sensor, Grove light sensor, and other sensors that output 0–5 V analog signals.
    • Digital sensor modules: touch sensor, PIR motion sensor, and other sensors that output only high/low logic levels.
    • Dedicated ultrasonic sensor.
    For instructions on connecting these compatible sensors to the board, please refer to the manual page.
  3. Not suitable for external cameras, gesture sensors, OLED displays, voice modules, or other I²C/UART extensible modules.
